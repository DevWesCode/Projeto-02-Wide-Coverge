# 🌍 Wide Coverage Locations - Your City Rides

Este é o meu **segundo projeto** utilizando apenas **HTML e CSS**, com o objetivo de praticar e consolidar os conhecimentos em estruturação de páginas e design responsivo.  
O projeto simula uma página institucional de um serviço de transporte urbano com uma proposta moderna e direta.

## 🚀 Funcionalidades

- Layout limpo e moderno  
- Navegação com links no cabeçalho  
- Estilização com CSS3  
- Responsividade parcial com uso de medidas relativas e `max-width`  
- Hover effects para botões e links  

## 💡 Aprendizados

Neste projeto, pude reforçar:

- O uso de fontes externas com o Google Fonts 
- Como aplicar `flexbox` para alinhar itens no cabeçalho  
- Como organizar imagens e seções lado a lado  
- Como melhorar a legibilidade e acessibilidade visual  
- Como aplicar efeitos de transição e hover no CSS  

## 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3
